# Code of Conduct — Contributor Covenant 2.1

## Pledge

Nos comprometemos a hacer de la comunidad un espacio libre de acoso para todos, sin importar edad, identidad, orientación, discapacidad, apariencia, raza, etnia, religión, nivel de experiencia o nivel socio-económico.

## Standards

Ejemplos de comportamiento positivo:
- Uso de lenguaje acogedor e inclusivo
- Respeto a diferentes puntos de vista y experiencias
- Aceptar críticas constructivas con gracia
- Enfocarse en lo mejor para la comunidad
- Mostrar empatía

## Enforcement

Reportar a `conduct@procurement-platform.local`. Toda queja será revisada y se tomará acción correctiva. Mantenedores pueden remover, editar o rechazar comentarios, commits, código, issues.

Ver https://www.contributor-covenant.org/version/2/1/code_of_conduct/ para versión completa.
